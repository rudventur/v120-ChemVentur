## 🚀 How to Run

1. Open `index.html` in a web browser
2. Press guns 1-3 to create strings
3. Watch them combine into subatomic particles!
4. Use gluon webs (Gun 5) to capture and fuse
5. Build your way to Uranium! ☢️
